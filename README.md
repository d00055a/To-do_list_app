# To-Do List App

## Overview

This project is a simple and interactive To-Do List web application built with HTML, CSS, and JavaScript. It was developed independently as part of a remote Web Development Internship at Codveda Technologies.

The application was created to practice core frontend fundamentals, including DOM manipulation, event handling, and client-side data persistence using localStorage.

## Project Scope

This is a frontend-only project focused on JavaScript fundamentals rather than backend logic or frameworks.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed or incomplete
- Persistent task storage using localStorage
- Modal alert when attempting to add an empty task
- Alternating left/right task layout
- Responsive layout with simple animations

## Tech Stack

- HTML5 – Page structure
- CSS3 – Styling and layout
- JavaScript (ES6) – Application logic and event handling
- localStorage – Client-side data persistence

## How It Works

1. Enter a task in the input field
2. Click **Add** to insert the task
3. Tasks are displayed in an alternating left/right layout
4. Click on a task to mark it as completed
5. Use the **X** button to remove individual tasks
6. Click **Clear All** to remove all tasks
